# VPlayer

Android video player (Kotlin, Jetpack Compose, Media3/ExoPlayer).

## ساخت APK بدون Android Studio
1. یک repository جدید در GitHub بسازید و همه فایل‌های این پوشه را در آن آپلود کنید (پوشه `.github` هم باید باشد).
2. به تب **Actions** بروید؛ workflow با نام **Build APK** خودکار اجرا می‌شود (یا Run workflow را بزنید).
3. بعد از حدود ۵ تا ۸ دقیقه روی run کلیک کنید و از بخش **Artifacts** فایل `VPlayer-apk` را دانلود کنید.
4. داخل zip فایل `app-release.apk` است؛ روی گوشی نصب کنید.
